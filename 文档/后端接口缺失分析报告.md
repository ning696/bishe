## 三、需要实现的接口清单

### 3.1 必须实现的接口（高优先级）

#### 1. 学生端提交投诉接口

**接口信息**:
- **路径**: `POST /student/complaint/add`
- **请求头**: `Authorization: Bearer {token}`
- **请求体**:
```json
{
  "enterpriseId": 1,
  "jobId": 1,
  "title": "投诉标题",
  "content": "投诉内容",
  "attachment": "http://localhost:9000/campus-hiring/attachment/complaint001.pdf"
}
```

**响应数据**:
```json
{
  "code": 1000,
  "msg": "操作成功",
  "data": 1
}
```

**业务逻辑**:
1. 从JWT Token获取学生ID（投诉人）
2. 验证企业ID和职位ID是否存在
3. 创建投诉记录（`complaint`表）：
   - `complaint_type`: 1（学生投诉企业）
   - `complainer_id`: 学生ID
   - `complainer_type`: 1（学生）
   - `complained_id`: 企业ID
   - `complained_type`: 2（企业）
   - `job_id`: 职位ID（可选）
   - `title`: 投诉标题
   - `content`: 投诉内容
   - `attachment`: 附件URL（可选）
   - `handle_status`: 0（待处理）
4. 返回投诉ID
