## 设计说明

### 1. 模块化设计
- `views/` 按 admin、student、enterprise 划分
- `api/` 按模块组织接口
- `router/modules/` 按模块拆分路由

### 2. 布局组件
- `layout/` 集中管理布局相关组件
- `Header.vue`、`Sidebar.vue`、`Breadcrumb.vue` 独立组件
- `useLayout.ts` 处理折叠/展开逻辑

### 3. 公共组件
- `components/common/` 通用组件（表格、表单、对话框等）
- `components/business/` 业务组件（职位卡片、简历卡片等）

### 4. 状态管理
- 使用 Pinia
- 按模块拆分 store（user、layout、admin、student、enterprise）

### 5. 类型安全
- `types/` 统一管理 TypeScript 类型
- 与接口文档字段对应

### 6. 工具函数
- `utils/` 统一管理工具函数
- `auth.ts` 处理 JWT Token
- `storage.ts` 持久化侧边栏状态

   - 配置 `store/` 状态管理

   - 先完成布局框架
   - 再开发登录/注册
   - 然后按模块逐步开发功能页面
